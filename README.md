# Controle de Notas - Java

Projeto desenvolvido durante meus estudos de Java, com o objetivo de praticar métodos, estruturas de repetição, condicionais e validação de dados.

## Sobre o projeto

O Controle de Notas é uma aplicação de console que permite cadastrar três notas de um aluno, calcular sua média e consultar sua situação acadêmica.

O programa utiliza um menu interativo para permitir que o usuário escolha as operações disponíveis.

## Funcionalidades

- Cadastro de três notas.
- Validação das notas, aceitando valores entre 0 e 10.
- Cálculo da média aritmética.
- Consulta da média cadastrada.
- Verificação da situação do aluno.
- Aprovação com média igual ou superior a 6.0.
- Tratamento de entradas inválidas.
- Menu interativo com opção para finalizar o programa.

## Conceitos de Java praticados

- Métodos e modularização.
- Métodos com parâmetros e retorno (`return`).
- Estrutura de repetição `do-while`.
- Estruturas condicionais `if`, `else if` e `else`.
- Variáveis e tipos primitivos.
- Variáveis booleanas.
- Entrada de dados com `Scanner`.
- Validação de dados.
- Formatação de números com `printf`.
- Configuração de localização com `Locale.US`.

## Organização dos métodos

O projeto utiliza métodos separados para organizar as responsabilidades:

- `MostrarMenu()`: exibe as opções disponíveis.
- `EscolhaDoMenuUm()`: apresenta as instruções para cadastrar notas.
- `LerNotas()`: recebe e valida a entrada de uma nota.
- `CalcularMedia()`: calcula a média das três notas.
- `AprovadoOuReprovado()`: verifica e apresenta a situação do aluno.
